Generated by `scripts/api_coverage.py` on 2026-10-20 from BoTorch source checkout (commit b0dd01be6) and botorch_rs 0.2.0. It lists every public class and function defined in a BoTorch module (re-exports counted once) and whether botorch_rs provides it under the same path. For names that exist in both, it lists the parameters of BoTorch's signature (`__init__` for classes) that botorch_rs does not accept and the public methods and properties of BoTorch's class that botorch_rs lacks. This static inventory excludes inherited Torch and GPyTorch APIs and overrides of `torch.nn.Module` methods, including `forward`, state dicts and buffers. Tensor backend factories can return actual `torch.nn.Module` implementations; their protocols require separate runtime checks. Accepting a parameter name (including through `**kwargs`) does not establish support for its values. The percentages below measure public-name availability, not behavior, GPU coverage, autograd equivalence or speed.
